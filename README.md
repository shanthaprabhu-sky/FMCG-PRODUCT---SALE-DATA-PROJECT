# Sales Data Management Project

A simple data management and analysis project using Excel datasets and Python scripts.  
This project is designed for practicing data handling, data processing, and basic analytics workflows.

---

##  Project Description

This repository contains sales-related datasets and Python programs used to manage and process business data such as:

- Orders
- Products
- Stores
- Transactions

The project helps in understanding:
- Data organization
- Python scripting
- File handling
- Basic business data processing

---

## Project Files

### Python Script Files
| File Name | Description |
|-----------|-------------|
| `order_table.py` | Python script for handling order data |
| `product_table_fmcg.py` | Script for product master processing |
| `store_table.py` | Script for managing store data |
| `transaction_table.py` | Script for transaction processing |
